# NeuroAccess test website

This is a fictional, single-page website for a transparent usability demonstration. It does not collect visitor data or accept bookings.

## Suggested NeuroAccess case

- **Target URL and allowed URL:** the published HTTPS GitHub Pages URL, including its trailing `/`.
- **Assessment goal:** Assess whether a participant can find the Flexible Focus workshop, identify its start time, and locate the registration note.
- **Target task:** On the workshop page, find the Flexible Focus session. Tell us when it starts and what the page says about registration. You may stop at any time.
- **Task step:** `step_1` — inspect the workshop list and session details.
- **Authorization basis:** This is my own demonstration website, published for the NeuroAccess test. Do not claim authorization for any other website.

The application separately handles participation consent and data-use consent. Do not enter personal information into the demo website.

## Publish with GitHub Pages

1. Create a repository that supports GitHub Pages, for example `neuroaccess-test-website`.
2. Upload `index.html` to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Use the resulting HTTPS Pages URL once GitHub reports the site is published. On an enterprise server, verify the actual URL and whether anonymous visitors can reach it.

If a repository URL is supplied and Git authentication is available, Codex can publish the file directly. This directory contains no course API key or NeuroAccess project data.
